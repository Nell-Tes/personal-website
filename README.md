# Helena Tesfaye · Personal Website

Personal portfolio for Helena Tesfaye, software engineer and computer science student at the University of Maryland.

The site covers projects, experience, skills, and leadership, with a small 3D book on the landing page that opens to a table of contents.

## Built with

- Next.js (App Router)
- React
- Tailwind CSS
- Geist font family

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing content

All text on the site lives in `lib/data.js`. Images and the résumé PDF are in `public/`.
